## Contribution checklist

- [ ] Confirm the issue is still open, desired, and within contribution guidelines.
- [ ] Discuss a non-trivial implementation with maintainers before investing heavily.
- [ ] Keep the change focused on the upstream project's needs.
- [ ] Add or update focused tests and documentation.
- [ ] Link the PR and record review feedback and final outcome.
- [ ] Do not describe an unmerged PR as a contribution accepted by the project.
